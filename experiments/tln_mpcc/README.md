# MPCC 전문가를 이용한 시간 이력 TLN 실험

맵은 `stack_master/maps/hangar_1905_v0`로 고정한다. 기존 `ofc/ofc/inference_node.py`와 기존 모델은 덮어쓰지 않는다. 실험 산출물은 `results/`에 저장한다.

이 구현은 독립적인 연구용 프로토타입이다. MPCC는 가상 경로 진행률을 상태로 두고 contour/lag 오차, 진행 보상, 속도 및 조향 변화 비용을 최적화한다. 단순 Pure Pursuit 제어기를 MPCC라고 부른 것이 아니다. 동역학은 운동학적 자전거 모델이며 검증에는 프로젝트의 F1TENTH 동역학·LiDAR·충돌 판정을 사용한다.

참고한 방법과 API:

- MPCC 개념, 경로 근사와 장애물 회피: https://github.com/alexliniger/MPCC
- CasADi NLP/Opti/IPOPT: https://web.casadi.org/docs/
- 전문가 데이터와 반복적 데이터 집약: https://msc.berkeley.edu/research/autonomous_driving_via_imitation_learning.html

## 파일 역할

- `world.py`: 지정 맵, race_manager와 같은 후보·난수 배치, 동역학 시뮬레이터 연결, 입력 전처리와 시간 이력.
- `expert_v4.py`: 주 수집 실험의 MPCC. 지역 선형화 경로, 2원 차량 근사와 장애물 제약, 경계 여유 비용, 횡가속도 제한. 기본 순항 목표 1.3 m/s, 상한 2.5 m/s.
- `expert_v5.py`: 장애물 사각형 및 차체 3원 근사와 선형화 지도 벽 거리 제약을 비교한 실험 구현.
- `expert.py`: 최신 개선 MPCC. 사각형 장애물·3원 차체, 비선형 지도 거리 제약을 사용. 이 파일의 존재가 모든 시험의 성공을 뜻하지 않는다. 결과 보고서에서 실제 성능을 확인한다.
- `collect.py`: 회차별 수집과 성공·실패를 함께 기록. 주 모방학습에는 성공 회차만 사용.
- `train.py`: 기존 TLN의 CNN·Dense 가중치를 이전한 확장 모델 학습. 첫 합성곱은 거리 정규화와 3프레임 입력을 보상한다.
- `dagger.py`: 학습 전용 추가 시드에서 학생이 방문한 상태에 MPCC 정답을 붙이는 1회 데이터 집약.
- `evaluate.py`: 리셋 없는 동일 배치 시험. 기존 TLN, 속도 제한만 완화한 기존 TLN, 학습 모델을 구분한다.
- `live.py`: ROS2 실시간 데모. 현재는 시뮬레이터 GT 위치·방향·속도를 사용한다.
- `test_contracts.py`: 스캔 무효값, 입력 크기, 시간 이력 초기화, 물리 단위 계약 확인.

## 입력 정보 차이

학생 입력은 `(541,3)` LiDAR 이력과 34차원 경로·상태 벡터다. 거리 0~10 m를 0~1로 정규화하고 0.1초 간격 3프레임을 쌓는다. 첫 관측에서는 같은 스캔을 복제하고 리셋 시 이력을 비운다.

경로·상태는 지역 경로점 8개의 차량 좌표계 x/y, 해당 위치의 좌우 경계 폭, 실제 속도, 이전 조향 명령이다. 지역 경로점과 경계 폭은 지도·위치 추정을 필요로 한다. 따라서 원래의 LiDAR 단독 TLN과 다른 **경로 조건부 확장 TLN**이다.

MPCC는 같은 지도 경로와 차량 상태를 사용하지만, 장애물은 LiDAR 시야·거리와 일치하는 것만 활성화한다. 활성화된 장애물 중심·방향은 시뮬레이터 정답을 이용하므로 학생의 원시 스캔과 완전히 같은 정보는 아니다. 이는 남아 있는 전문가의 인지 특권이며 최종 보고서에 제한으로 기록한다. 이를 숨기거나 학생이 정밀 장애물 좌표를 입력받는다고 주장하지 않는다.

시뮬레이션에서는 위치 추정 오차를 제거하기 위해 GT를 사용한다. 실차에서는 PF/추정 odometry와 TF로 동일한 지역 좌표를 만들어야 하고 별도 검증이 필요하다.

## 출력 계약과 지연

정답은 `[조향각(rad)/0.36, 목표속도(m/s)/2.5]`다. 출력 활성화는 각각 tanh, sigmoid다. 추론은 `[출력0*0.36, 출력1*2.5]`로 복원하고 범위만 제한한다. 속도 0을 허용하며 3 m/s 최저속도, 조향 기반 중복 감속, EMA는 적용하지 않는다.

MPCC의 최적화 입력 자체가 목표 조향각·목표 속도이므로 가속도나 조향각속도를 잘못 정답으로 사용하는 문제가 없다. 단, 내부 예측 속도 응답은 시뮬레이터의 하위 제어를 단순 근사하므로 모델 오차가 남는다.

실시간 데모는 10 Hz 제어, 깊이 1의 최신 스캔 수신, 오래된 스캔 정지를 사용한다. MPCC의 계산이 제어 주기를 초과하면 데모에서 성능이 악화될 수 있다. 학생의 처리 시간은 별도 계측하며 센서부터 작동기까지의 전체 지연과 구분한다.

## 데이터와 평가 해석

학습 시드 100~115, 검증 시드 200~203을 사용한다. 검증 성공 회차가 적다는 점을 반드시 보고한다. 2026은 기존 데모와 개발에서 사용했으므로 미관측 평가 시드로 주장하지 않는다. 평가 시드 300~304는 학습·전문가 튜닝에 사용하지 않는다.

모든 실패 회차도 JSON에 남긴다. 솔버 실패의 정지 명령을 전문가 최적 행동으로 간주하지 않으며, 충돌 이후 스캔을 정상 학습 정답으로 사용하지 않는다. 성공 회차만 학습하는 방식에는 선택 편향이 있으므로 별도 폐루프 평가가 필수다.

`pilot_v1`, `pilot_v2`, `pilot_v3`는 실패와 수정 과정을 보존한 기록으로 최종 학습과 섞지 않는다. 코드 해시와 실제 배치, 명령, 궤적을 같이 보존한다. 이전의 race_result 파일은 비교 평가에 재사용하지 않는다.

재현 명령과 측정된 최종 결과는 `REPORT_KO.md`를 확인한다.
