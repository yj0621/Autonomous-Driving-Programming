# 직선 고속 및 코너 감속 녹화 결과

맵: hangar_1905_v0. 기존 모델 가중치와 이전 실험 데이터는 새 학습에 사용하지 않았다.

## 실제 ROS 녹화

- 위치: `ros_basic_fast_3p0/`
- 물리 시간 84.9초, 완전한 경로 순환 3회.
- 충돌 메시지 0회, 위치 재설정 메시지 0회.
- 직선 평균 실측 속도: 2.971m/s. 기준 곡률 0.08/m 미만.
- 급코너 평균 실측 속도: 1.416m/s. 기준 곡률 0.55/m 초과.
- 전체 평균 실측 속도: 2.293m/s. 최고 속도: 3.0m/s.
- 명령 조향 변화량 95백분위: 0.0417rad.
- 속도 계획은 6m 앞 곡률과 제동거리로 코너 진입 전 감속한다.
- 이 기본 주행 녹화에는 장애물을 배치하지 않았다. 장애물 회피 성능 증거로 사용하면 안 된다.

## 새 모델 학습

새 무작위 초기값에서 시간 이력을 받는 CNN/GRU를 학습했다. 입력은 라이다 4프레임, 레이스라인과 지도 폭, 속도와 조향, 관측한 장애물 기억, 9m 경로 정보다. 정답에 사용한 장애물 실제 좌표는 모델 입력에 들어가지 않는다. 좌우 회피 경로를 별도 출력하여 서로 다른 회피 경로의 평균화를 줄인다.

학습은 새 기본 주행 8개, 새 ROS 기본 주행 3개, 새 무작위 장애물 회피 31개, 새 MPCC 주행 7개로 구성한다. 실패한 교사 주행은 성공 데이터에서 제외하고 진단 기록으로 보관한다. 검증과 시험 배치는 학습에 사용하지 않는다.

첫 후보의 검증 10개 중 완주 7개, 벽 충돌 2개, 장애물 충돌 1개였다. 따라서 아직 최종 회피 성능이 확보된 모델로 볼 수 없다. 최종 결과는 별도 평가 파일에 기록한다. 복구를 위한 위치 재설정은 완주 성공에 포함하지 않는다.
